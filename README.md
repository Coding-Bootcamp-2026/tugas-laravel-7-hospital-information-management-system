# tugas-laravel-7-hospital-information-management-system
Tugas untuk merancang dan membangun Sistem Informasi Manajemen Rumah Sakit menggunakan Laravel. Penekanan utama pada penugasan ini adalah penerapan untuk mengelola skema database yang berskala besar. Tugas untuk membangun Dashboard dengan modul CRUD saling terhubung, sehingga dapat beroperasi sebagaimana sistem rumah sakit pada dunia nyata.
